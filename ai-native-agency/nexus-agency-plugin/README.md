# NEXUS Agency Plugin

AI-native advertising agency operations system for Claude Code. Replaces 103-day linear waterfall with 6 concurrent engines running in 8-10 days.

## Architecture

```
6 ENGINES | 24 SKILLS | 13 SCRIPTS | 12 COMMANDS | 4 AGENTS
```

### Engines

| Engine | Skills | Purpose |
|--------|--------|---------|
| **Orchestrator** | 3 | Campaign lifecycle management |
| **Intelligence** | 3 | Always-on market awareness |
| **Architect** | 5 | Strategy + Planning + Measurement + MMM Meridian |
| **Activation** | 4 | Creative + Setup + Optimization |
| **Value** | 4 | Measurement (always-on from Day 0) |
| **Governance** | 3 | Waste detection + Supply chain transparency |
| **Cross-Cutting** | 2 | Quality + Learning across engines |

### Data Input Modes

1. **Manual input** (required) - Upload/paste data as JSON, CSV, or text
2. **MCP platform connectors** (optional) - Live connections to Google Ads, Meta, DV360, TikTok, Amazon, X, LinkedIn
3. **MCP GCP connector** (optional) - Google Cloud Platform (BigQuery, Cloud Storage)

### Commands

| Command | Purpose |
|---------|---------|
| `/campaign` | Full campaign intake and kickoff |
| `/intelligence` | Latest intel report |
| `/architect` | Strategy + planning |
| `/activate` | Campaign launch |
| `/pulse` | Real-time health check |
| `/revenue` | Revenue attribution report |
| `/csuite` | Executive summary (CEO/CFO/CMO) |
| `/optimize` | Manual optimization review |
| `/learnings` | Cross-campaign insights |
| `/qa` | Quality validation |
| `/governance` | Full governance audit |
| `/waste` | Media waste waterfall analysis |

### Key Principles

1. **Measurement First** - Framework designed BEFORE strategy
2. **True Concurrency** - Intelligence + Value + Governance start Day 0
3. **Financial Language** - Every output connects to revenue/P&L
4. **Continuous Operations** - Optimization and reconciliation are always-on
5. **Proactive Governance** - Waste is quantified and prevented, not discovered after the fact

The question is never "Did we spend the budget?" but "Did we waste the budget?"

## Market Defaults

Mexico/LATAM benchmarks for 5 verticals: Automotive, FMCG, Financial, Retail, Telecom.

## Governance Maturity: Stage 5 (Optimized)

Always-on governance with conservative thresholds. Actual data preferred over benchmark estimates.
