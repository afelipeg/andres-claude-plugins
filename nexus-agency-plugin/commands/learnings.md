# /learnings

## Usage

```
/learnings [vertical or client]
/learnings --channel [channel_name]
/learnings --creative
/learnings --governance
/learnings --export
```

## Workflow

1. **Cross-cutting**: Pull accumulated learnings via `learning-accumulator`
2. **Intelligence**: Cross-reference with current benchmarks via `performance-oracle`
3. **Governance**: Include waste trend learnings via `waste-quantifier`
4. Filter by relevance to current context (vertical, channel, objective)

## Engines Activated
- Cross-cutting (learning-accumulator)
- Intelligence (performance-oracle)
- Governance (waste-quantifier)

## Output
Curated learnings report with high-confidence insights, new discoveries, anti-patterns to avoid, benchmark updates, and governance trends.
